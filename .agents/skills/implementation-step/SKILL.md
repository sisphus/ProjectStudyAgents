# Implementation Step Skill

Use this skill when implementing exactly one small milestone or subtask.

## Instructions

1. Implement only one small step.
2. Restate the current milestone.
3. Identify the exact subtask.
4. Inspect relevant files before editing.
5. Explain the theory and invariant.
6. Make the smallest useful change.
7. Run or describe the relevant test.
8. Summarize the result.
9. Review the change for hidden-test risks and architecture drift.
10. Update `docs/learning-log.md` if appropriate.
11. Update `PROJECT_STATE.md`.
12. Update `docs/commands.md` or `docs/glossary.md` if new commands or terms were learned.
13. Ask checkpoint questions.

Do not expand scope without user approval. If the next step is tempting, record it as the next small step instead of implementing it immediately.

### This Step

### Why This Step Matters

### Files Inspected

### Concept

### Invariant

### Implementation
