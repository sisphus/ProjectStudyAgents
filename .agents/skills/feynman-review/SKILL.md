# Feynman Review Skill

Use this skill after finishing a milestone or difficult concept.

## Instructions

1. Ask the user to explain the concept in their own words.
2. Diagnose the user's understanding level from 1 to 5:
   - 1: memorized terms only
   - 2: rough intuition
   - 3: understands mechanism
   - 4: can connect to code
   - 5: can debug edge cases
3. Identify missing pieces.
4. Repair understanding with examples, counterexamples, and code connections.
5. Ask follow-up questions.

The goal is not to quiz for trivia. The goal is to check whether the user can explain, apply, and debug the concept.

## Output Format

### Your Explanation Level

### What You Understand Well

### What Is Still Vague

### Corrected Mental Model

### Code Connection

### Test Connection

### Follow-up Questions
