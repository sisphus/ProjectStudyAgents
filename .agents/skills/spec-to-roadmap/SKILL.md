# Spec To Roadmap Skill

Use this skill before implementation begins.

## Instructions

1. Read `SPEC.md`.
2. Read `PROJECT_INTAKE.md`.
3. Inspect the starter-code layout.
4. Identify build and test commands.
5. Extract concrete requirements.
6. Separate required features from optional features.
7. Identify constraints, deliverables, performance expectations, and submission rules.
8. Record reproducible commands in `docs/commands.md`.
9. Build a concept map in `docs/concept-map.md`.
10. Add key terms to `docs/glossary.md`.
11. Split the project into small milestones.
12. Order milestones by dependency.
13. Add a clear "Done When" definition to each milestone.
14. Identify the first smallest implementation task.
15. Update `docs/milestone-roadmap.md`.
16. Update `PROJECT_STATE.md` with current milestone, commands, open questions, and next recommended prompt.

Do not write implementation code during this skill unless the user explicitly asks for code changes.
